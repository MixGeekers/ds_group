# S04 一边做事，一边聊天

[目录](<../目录.md>) · [共同约定](<../实验计划.md>)

状态：DEV 种子，设计建议，未执行。优先级：首轮重点。关联 V04/V05/V10/V11/V23。

初始：U 在 C-priv；获准只读材料 fixture://docs/A、B，材料均为合成，允许本会话产出比较表，不允许采购或写回。后台 worker 使用一个槽位；对话槽可用。时间用显式屏障控制，不测真实延迟。

| 步骤／输入 | 路由 | 记忆、关系与其他状态 | 工具／发送轨迹 | 拒绝项与 oracle |
|---|---|---|---|---|
| S04.1／U：“比较 A、B 两份方案，给我一张成本和退订条件表。”刻意误分到快路 | R 返回 needs_core，原事件一次升级 C → W | 唯一 Task/Assignment；M/R 不变 | replyer 工具=0；受理后 worker 仅读 A/B，D=1 告知受理 | 不在 R 中执行或声称已完成；重复 needs_core 返回原路由/任务，不制造新事件或二次 Task。H1/H3 |
| S04.2／U 带同一 taskId 补充：“B 的报价页有更新，请以附件 B-r2 为准。”附件仍在原授权范围 | P → 既有 worker TaskInput | Task 输入版本更新，旧 B-r1 结果不得作为当前结论；M/R 不变 | 读取 B-r2；D=1 简短接收说明，无新 Task | 不能因每次补充另建工作；旧输入未核验也不能报已更新完成。H3/H7 |
| S04.3／U：“先解释一下‘退订窗口’是什么意思。”replyer 草稿生成后、发送前卡住 | R | 当前 DialogueTurn/草稿变；后台 Task 继续。M/R 不变 | 文字生成，无任务工具；此时发送 0 | 查询/闲聊不能取消后台工作；解释不等待 worker 完成。功能检查 |
| S04.4／U 在旧草稿发出前：“一句话就好。”旧生成器故意忽略 abort 并迟到返回长文 | R，新 generation | S04.3 草稿失效，Task 仍继续，M/R 不变 | 旧长文发送=0；新一句话 D=1 | 发送前代次检查必须拦截，不能依靠模型自己停止；不是按新消息数量取消 Task。H4 |
| S04.5／worker 交来“比较已完成”，没有 A 的来源也没有成本证据；U 同时问：“表格好了没有？” | P 核验 → R 状态查询 | Task 未达 completionSpec，维持未完成并注明缺项；M/R 不变 | D=1，如实说明仍缺 A 的依据；成果通知=0 | worker 自述不够判 succeeded；不能编成本补表，也不能把状态查询路由回长任务等待。H7；功能 |
| S04.6／在 worker 下一次读取前，U 通过明确 taskId 的控制入口：“取消这张比较表。”随后 worker 确认已停，旧 Assignment 再迟到交结果 | K → P → R | 先拒绝新动作；有停止证明后 Task cancelled；迟到结果不能覆盖。M/R 不变 | 停止/核对一次，D=1；屏障后的新读取/成果外发=0 | 没有外部未知副作用的本例可确认取消；若无停止证据应走 S05 的 unknown，不硬套 cancelled。H4 |

功能里程碑：误分能安全升级且接单一次；任务可接收范围内补充；对话能及时回答；普通聊天不取消任务；明确取消能生效。实际 P95 等性能指标不由这些屏障步骤推出。

后续正例分支：用具备完整 A/B-r2 来源的合法结果替换 S04.5，核验后必须交付表格；不可因防范无证据结果而永远不接受正确结果。此分支将独立计数，未算入六步主线。
