# 跨模块契约的一手依据

日期：2026-11-01。范围：官方标准说明阅读；未执行标准符合性测试。领域字段、状态机、权限与默认参数均为识雨的设计建议，不是标准提供的成品 Agent 能力。

| 来源 | 本轮核查要点 | 对方案的用途与限制 |
|---|---|---|
| [CloudEvents 1.0.2](<https://github.com/cloudevents/spec/blob/v1.0.2/cloudevents/spec.md>) | 供应商中立事件格式，定义上下文与事件数据，并要求支持 JSON 格式 | 用于外部入口格式与映射；不提供身份授权、任务状态或幂等业务实现 |
| [JSON Schema 2020-12](<https://json-schema.org/draft/2020-12>) | 固定的 schema 方言与验证文档；格式注解和断言有区别 | 合同与参数验证复用成熟实现，仍需独立语义校验 |
| [Ajv v8.20.0 package.json](<https://github.com/ajv-validator/ajv/blob/v8.20.0/package.json>) | GitHub connector读取固定标签的版本及MIT许可声明 | 作为严格2020-12校验器的验证候选；尚未安装或运行 |
| [W3C Trace Context Level 1](<https://www.w3.org/TR/2021/REC-trace-context-1-20211123/>) | 规定跨服务传递追踪上下文的 HTTP 字段与格式 | 按需复用 traceparent；不把 trace ID 当授权或业务去重键 |
| [SQLite WAL 文档](<https://www.sqlite.org/wal.html>) | WAL 要求访问者在同主机，不能把网络文件系统当正常 WAL 共享盘；跨 ATTACH 数据库并非整体原子 | 权威账本和 outbox 在同一个本地数据库中；真实 SQLite 版本门槛见数据专题证据 |

DSH 工具、Session、领域存储及 Superagent 原型的限定源码核查，由本目录相应专题记录。总体选择引用这些证据，不重复宣称本轮运行了候选。
