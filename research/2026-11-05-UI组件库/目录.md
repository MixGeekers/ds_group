# UI 组件库调研来源

检索于 2026-11-05（America/Caracas）。问题是为 DSCord 聊天客户端和独立管理后台选择公共 React 控件体系。结论见[候选记录](<../../技术候选/DSCord界面组件库.md>)。

## 官方资料

| 来源 | 核对内容 |
|---|---|
| [shadcn Introduction](https://ui.shadcn.com/docs) | 可编辑源码、组合接口及默认样式 |

| [shadcn Theming](https://ui.shadcn.com/docs/theming) | CSS 变量、语义 token 和深色映射 |
| [shadcn Base Dialog](https://ui.shadcn.com/docs/components/base/dialog) | Base UI 包装、弹窗组合及 RTL 文档入口 |
| [Base UI About](https://base-ui.com/react/overview/about) | CSS 适配、React 和打包工具支持声明 |
| [Base UI Accessibility](https://base-ui.com/react/overview/accessibility) | 键盘、焦点管理、ARIA 与应用侧标签职责 |
| [Mantine](https://mantine.dev/) | 组件和 hooks 范围 |
| [MantineProvider](https://mantine.dev/theming/mantine-provider/) | 颜色模式、主题对象和 CSS 变量 |
| [Mantine use-form](https://mantine.dev/form/use-form/) | 表单状态与校验 |
| [Ant Design Introduction](https://ant.design/docs/react/introduce/) | React 组件体系 |
| [Ant Design Table](https://ant.design/components/table/) | 筛选、排序、行选择与虚拟表格 |
| [Ant Design Internationalization](https://ant.design/docs/react/i18n/) | ConfigProvider 与组件语言包 |

## 限定源码核查

[source-check.json](source-check.json) 保存 GitHub 固定提交、来源 URL、读取文件的 SHA-256、包版本及选取的源码行。核查覆盖 shadcn 的 Base Dialog、Base UI 的 DialogPopup、四个候选的包清单和两个主选候选的根许可证。官方维护分支快照与候选发布包在正式接入时还需逐项核对。

本轮证据为资料阅读和限定静态核查。浏览器兼容性、性能、构建体积及 DSCord 内的运行表现留待验证切片。
