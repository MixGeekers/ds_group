## 可以复用什么

| 内层职责 | 真实公共入口 | 核查结论与边界 |
|---|---|---|
| 记忆检索 | `breath_search` / `breath_advanced` | 关键词/BM25+向量融合，返回当前正文；自动召回应显式传 `mode=automatic`，使 dont_surface/digested 生效；`with_ids=true` 带 schema=1 的文本尾部清单 |
| 感受/情绪 | `feel(query,max_tokens)`；写入为 `hold(feel=true,source_bucket=...)` | 可读既有感受；显式感受写入依赖原始桶；不等于识雨拥有短时情绪状态机 |
| 认知回顾 | `dream` | 原生候选/回顾可复用，但会记录不同日期的见证、发 webhook，属于受控变更，不是只读查询 |
| 自我认知 | `I(read=true)`；`I(content/aspect/promote/supersedes)` | 候选先为普通记忆，满足原生见证条件后显式晋升；正式 I 的最近三条可由其 SessionStart 机制注入。识雨不自动把这些文本发布为稳定人格或系统指令 |
| 关系 | You / Them 可选服务 | 第一批关闭。已有资料和源码显示 Them surface 带人物状态/待处理通知行为；不能当无副作用只读关系图 |
| 能力 | 无对应本体能力注册入口 | 仍复用 DSH skills/tool registry；Ombre 不覆盖全部内层六部分 |

`breath` 检索分支自身不再强化命中桶，但 dispatch 会启动 decay engine、记录操作和工具事件。包装器还会追加/消费删除通知，Them 启用时会调用其 surface。因而“no touch”不能扩大为整次调用无状态变更。[breath dispatch](https://github.com/P0luz/Ombre-Brain/blob/115d831d979bf67efc7150f976e2cb34c333c935/src/tools/breath/__init__.py)、[search](https://github.com/P0luz/Ombre-Brain/blob/115d831d979bf67efc7150f976e2cb34c333c935/src/tools/breath/search.py)、[dream](https://github.com/P0luz/Ombre-Brain/blob/115d831d979bf67efc7150f976e2cb34c333c935/src/tools/dream/__init__.py)、[I core](https://github.com/P0luz/Ombre-Brain/blob/115d831d979bf67efc7150f976e2cb34c333c935/src/tools/i/core.py)。

## namespace、版本与写入回执

官方 MULTI_OWNER 明确一 owner 对应一个独立 instance/vault/port；`OWNER_NAME/COUNT` 只是显示信息。上述 tools 没有每请求 namespace 身份参数。domain、tags 是检索筛选，不是访问控制。适配器按受信部署固定 vaultScope，只接受同 scope 请求；这只是路由，不认证 actor。对多频道/私聊的 audience 裁剪尚未闭环，不能把共享私密 vault 内容直接交给 replyer。[MULTI_OWNER](https://github.com/P0luz/Ombre-Brain/blob/115d831d979bf67efc7150f976e2cb34c333c935/docs/MULTI_OWNER.md)。

公共 hold/trace/I 签名没有 operationId、expectedVersion 或原子 compare-and-swap 参数。`hold` 会做模型打标、`merge_or_create`，并安排 plan resolution / duplicate 检查；重复发起不保证创建同一桶。普通返回是文本，包装器除 ToolInputError 外还会把运行异常转换为文本；因此 MCP `isError=false` 不能证明变更成功。[hold core](https://github.com/P0luz/Ombre-Brain/blob/115d831d979bf67efc7150f976e2cb34c333c935/src/tools/hold/core.py)、[公共包装器](https://github.com/P0luz/Ombre-Brain/blob/115d831d979bf67efc7150f976e2cb34c333c935/src/server.py#L578)。

识雨的控制库只应记录 MemoryOperation、来源/target 引用、授权、Effect 与回执。已观察到同样正文或相似搜索结果，不能证明是某次 operation 的写入；内容 hash 也不构成后端 CAS。写后断连保持 unknown，不自动重放；CAS 需求无原生能力必须拒绝。当前自动写入关闭，不使用 SQLite 记忆 fallback。

## 删除、导出与恢复

`trace(delete=true)` 归档 Markdown 并清理可重建 embedding；`hard_delete=true` 仅允许创建时显式 test_data 且可擦除的测试桶，并要求理由。普通归档不等于用户数据彻底清除。本轮没有证明普通桶、source、关联、索引、备份的端到端清除凭据，因此不开放自动删除。[trace core](https://github.com/P0luz/Ombre-Brain/blob/115d831d979bf67efc7150f976e2cb34c333c935/src/tools/trace/core.py)、[web buckets](https://github.com/P0luz/Ombre-Brain/blob/115d831d979bf67efc7150f976e2cb34c333c935/src/web/buckets.py)。

原生导出是经认证的 Web `GET /api/export`，不是已注册 MCP tool；导出桶 Markdown、SQLite 快照、meta 与 SHA-256 manifest，不导出含凭据的 config。原文引用与可选 You/Them 状态也在其原生备份实现处理。manifest 是完整性校验，不是签发者证明；多个组件分别导出也不表示跨组件原子快照。识雨应消费原生导出并保存控制域恢复清单，不另写 ZIP/备份引擎。[import_api](https://github.com/P0luz/Ombre-Brain/blob/115d831d979bf67efc7150f976e2cb34c333c935/src/web/import_api.py#L1421)、[backup_archive](https://github.com/P0luz/Ombre-Brain/blob/115d831d979bf67efc7150f976e2cb34c333c935/src/ombrebrain/storage/backup_archive.py)。
