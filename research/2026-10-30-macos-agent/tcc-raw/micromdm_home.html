MicroMDM organization projects

  • NanoMDM

    A minimalist Apple MDM server and library heavily inspired by MicroMDM

    NanoMDM on GitHub

  • NanoDEP

    A set of tools, and a Go library powering them, for communicating with Apple's Device Enrollment Program (DEP) API servers.

    NanoDEP on GitHub

  • NanoCMD

    A Go library and server for Apple MDM command workflows

    NanoCMD on GitHub

  • NanoHUB

    Adapts and unifies NanoMDM, NanoCMD, and KMFDDM into a single MDM server. Intended as a library it includes a reference command-line server as well.

    NanoHUB on GitHub

  • NanoAXM

    A set of tools and Go libraries powering them for communicating with the Apple School and Business Manager API.

    NanoAXM on GitHub

  • KMFDDM

    An Apple Declarative Device Management (DDM) server. It works together with NanoMDM. A MicroMDM organization sister project.

    KMFDDM on GitHub

What's new with the MicroMDM organization?

Organization-linked Activation Lock & Bypass

To quote our friends over at Iru (formerly Kandji):

Activation Lock is a theft-deterrent feature found in iOS and iPadOS devices and modern Mac computers (with the Apple T2 Security chip and Apple silicon).

NanoMDM and NanoDEP now have direct support for organization-linked Activation Lock, the flavor of Activation Lock that is not tied to a user’s Apple Account (i.e. not “Find My”). NanoDEP (as of v0.7.0) can lock a device to your organization using the Apple DEP API, and NanoMDM (as of v0.9.0) can unlock a device using Apple’s Escrow Key Unlock endpoint. Both sides revolve around the humble Activation Lock Bypass Code. Below we’ll walk through both, step by step.
