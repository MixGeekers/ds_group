# Lab 原型实施与方向修正记录

> 本文保留第一阶段独立原型的历史结果。后续“识雨健身房”DSH 插件、多路径成果验收及新增测试见[插件实施记录](<插件实施记录.md>)。

2026-11-01（America/Caracas）。本轮实测，Node v24.19.0；项目依赖由 package-lock.json 固定。用户已授权测试系统实施并指定 `lab/`；随后要求评估 DSH 插件基座和多路径成果验收，故现有实现保留为验证原型，未安装或迁移到 DSH。

## 实际交付

- TypeScript/Fastify 本机服务、React Web 控制台、SQLite 运行索引和独立 JSONL 事件。
- 12 名职员、6 部门、3 家供应商、22 会话；4 场景、8 工作科目及真实合成文件。
- 独立输入计划、可重复噪声、并发参考 worker、依赖接续、有限分支响应式演员、停止/排空和历史恢复。
- 文件与有状态服务工具，操作幂等、一次工具故障、实际效果发生后回执丢失。
- 外部 Agent 接缝、公开交付协议、程序事实验收、外部评分 HTTP/JSON 导入、评审证据导出。
- Web 运行配置、时间线、任务、成果下载/预览、验收、评审、比较和移动端布局。

这些是 Lab 能力。参考执行器是确定性代码，不是识雨模型；真实 core、worker、replyer、长期记忆及内层六域未接入验证。服务维护作用于有状态替身，不是实际生产主机。外部评分测试使用本机 stub，没有调用付费模型。

## 验证结果

| 命令/检查 | 本轮结果 |
|---|---|
| `npm test` | 最终 **55/55 通过**，21.43 秒；覆盖八类成果、反例、协议、并发限额、迟到交付、关闭竞态、故障、评分与路径边界 |
| `npm run build` | TypeScript 与 Vite 构建通过 |
| `npm run smoke` | **5/5 运行通过**：普通工作日8/8、高噪声400条8/8、一次工具失败4/4、丢回执4/4、记忆场景业务交付3/3；不是记忆智能通过 |
| `npm run test:ui` | **1/1 浏览器端到端通过**，18.7 秒；实际启动、18产物、下载预览、有效/无效评分导入、证据跳转、对比、外部停止；无 pageerror，390px 无横向溢出 |
| 外部 Agent 协议专例 | 通过 HTTP 接缝读取输入、调用工具、完成8科；目标工作目录不可访问，丢回执同ID重试只产生一次效果；使用参考算法，不证明外部模型能力 |
| Node SQLite | 本机可创建/查询/关闭；SQLite版本3.53.3 |

初次沙箱运行的4项 HTTP 测试因禁止监听回环端口报 EPERM；在允许临时本机端口的执行环境复验通过。一次把整组测试与高噪声 smoke 并发运行造成真实磁盘/事件处理竞争，10秒时限例中断（54/55）；未放宽该例时限，改为按测试文件串行执行并与 smoke 分开后55/55通过。该记录不作为吞吐或生产 SLA 证明。

修正了：接单确认误算最终交付、外部 Agent 完成状态先于交付导致过早封存、并发创建未预留容量、关闭时未等验收、正确JSON掩盖损坏人读产物等问题。当前仍有固定任务路径/文件类型/部分文本匹配约束，属于协议自检范围，不代表自然职员任务唯一正确方式。

依赖安装审计报告10项 moderate、0 high/critical，主要经 ExcelJS 归档依赖及静态文件插件的 glob/uuid/minimatch 链；未用强制降级掩盖，也未据此声称完成安全审计。当前为本机合成数据原型，正式集成时需继续核对依赖替换和实际调用路径。DSH插件方案可减少独立静态宿主等依赖。
