# 蓝桥合成公司工作资产

所有人物、订单、金额与系统数据均为合成开发样本。运行时复制到各 run 的 `workspace/inputs/`，不同运行不共享可变工作文件。八类业务输入由 `src/catalog.ts` 关联；结果统一输出到 `outputs/<taskId>/result.json` 及对应可读文件。

[公开输出协议](<output-contracts.json>)定义八科 `result.json` 的字段、JSON Schema（draft-07）和业务口径。每项任务的 inputs 与 instructions 都指向它，外部 Agent 无需查看验收器源码即可知道如何交付机器可核验的成果。协议不包含本场景的计算答案或评分结果；数组的无业务意义顺序、可行方案与自然语言表达允许合理变化。具体交付文件名以任务的 `deliverables` 为准。

这些文件只提供正常完成任务所需的数据，不含评分答案。参考执行器用于自检 Lab 的工具、产物和验收闭环；它不代表识雨模型或六域能力已通过。

系统巡检与维护操作的是 Lab 有状态服务替身，健康值来自当前配置。它不代表真实服务部署、真实网络或操作系统维护能力。
