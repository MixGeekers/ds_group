## 0.3.0 本轮推进

当前版本为 **0.3.0**，已在当前 DSH 关闭再开启插件后复验。本轮补齐多人房间、真人参与、共享文件、自定义剧本、外部目标接入和独立模型设置，并使用当前 DSH 实页及一次真实目标/Judge 任务核验。自动测试、原生宿主操作和真实模型样本分别记录；下文保留 0.2.0 历史结果。

- 房间区分真人 `HUMAN`、被测对象 `SHIYU` 和剧本职员；支持群聊、目标私聊、任务发布、共享附件、工作区预览及成果送达。职员私聊对真人只读，上传文件需实际分享或附入任务后才对目标可读。
- 剧本可从内置案例保存副本，编辑角色、会话、定时输入、任务和资料；保存检查引用与版本冲突，每次运行保留自己的公司和剧本快照。未知自定义数据结构不套用内置业务答案，缺文件或文件被篡改仍会被独立检查发现。
- 外部 DSH 会话和 HTTP 客户端可按房间接入；接入、断开、封存和历史回执各有边界。重复请求复用原操作身份，明确未执行的前置条件失败可纠正后重试；新业务写入不能通过封存回执通道继续执行。
- 设置页复用 DSH 的模型目录元数据和 `llm.resolveCallConfig` 校验。目标 Agent 与 Judge 分别选择模型及思考强度，默认均为 `follow_host`；只保存 Lab 内的模型标识，不写宿主全局模型选择、服务地址或凭据。变更仅作用于新建 Session，正在运行的 Session 保留启动时模型快照。
- 本轮用户已自行将两角色都保存为 `opencode-go / deepseek-v4.1-flash / max`。这证明设置已保存，**不代表该新选择已经跑过真实目标或评分任务**；下方真实任务发生于此前设置下。
- `keepOpen` 房间到期时，只有剧本输入结束、引擎内工作与演员响应清空，且所有已引入任务都有真实交付，才正常封存为 `completed`；零任务自由聊天也可正常封存。仍有待交付任务或在途引擎工作则保留 `interrupted`。任务自述完成不够，正常封存不提高业务通过数；模型调用仍受原有时间和步骤预算控制。

## 0.2.0 已实现（历史基线）

- 包 `@shiyu/gym`，版本 0.2.0；代码、构建、合成资料及运行数据全部保留在 `lab/`。独立 Fastify/React 原型继续可运行。
- 原生侧栏入口及主面板，使用宿主 React、locale 与主题；不使用 iframe，不另起服务。界面包含场景、参数、运行历史、任务、分页事件、产物预览下载、事实验收、评分和对比。
- Host 复用 Lab 引擎；工具 `shiyu_gym` 与界面通过同一服务操作。只读观察请求不会触发模型；启动、评分、停止由明确操作驱动。
- DSH 模型训练通过 `ctx.agents.create` 创建独立 Session/cwd；仅暴露本次运行的 `gym_target` 工具，隐藏继承工具并用 guard 拒绝其他执行。支持通用 XLSX/DOCX 生成，不内置业务标准答案。
- Judge 使用另一个独立 Session，只能通过 `gym_review` 读取封存证据、输入、真实产物和服务事实并提交新意见。不能修改业务世界或覆盖程序事实。没有有效提交时记录 `judge_error`，不编造分数。
- 提供步骤/时间预算、取消、卸载清理、单写者锁、持久请求去重、历史恢复。重启将活动模型标为中断，不自动续跑；已封存的管理型 Session 不能恢复为无限制 Agent。
- 默认训练最多80个模型步骤、300秒；默认Judge最多24步、180秒。实际token费用以DSH Session记录为准，未测量时不填零。

## 多路径成果验收

保留 `protocol` 固定协议自检；新增 `outcome` 业务成果模式。参考执行器只运行 protocol；DSH训练默认 outcome。

任务给出业务目标、必要约束和可接受交付，不再强制标准 `result.json`、固定文件名、固定工具顺序或唯一最低价推荐。成果仍必须位于任务自己的输出空间，保障隔离。通过 `task.deliver {taskId,paths,text}` 明确提交；实际接收人来自任务，不由被测Agent任意改写。

提交检查实际登记文件、任务归属、SHA256、最新写入及送达顺序。报表、对账、报价、分配和服务状态有有限的独立事实核对；不同格式无法可靠解析时保留不可判定，不自动判失败。文件存在、文本足够长或完成声明均不等于业务正确。

`tasksSubmitted` 表示有效提交数；`tasksPassed` 只表示可独立确认的业务通过数。多数业务主任务仍需 Judge 查看成果，界面明确显示“有效提交，业务质量待评分”。模型评审保留为独立意见，不覆盖程序事实。

## 当前边界

1. 此处“训练”是任务练习与评测，不是模型权重训练；普通DSH模型基线不是识雨产品内核。
2. 模拟职员仍为脚本及有限响应分支；没有宣称真实core/worker/replyer、长期记忆、情绪或人格已验证。
3. 工具作用域隔离不是操作系统/容器盲测；同一系统用户可读开发源码。正式保留集仍需进程、数据权限和角色凭据隔离。
4. Judge判断具有模型误差，需要校准、复评与人工复核；未知格式不假装已经理解。
5. 当前是限定版本的本机DEV插件；依赖安全审计、跨宿主故障与真实模型性能基准仍未完成。

## 2026-11-02：3H A 结束后的空数组导入修补
