## 0.1.0 本轮实现

- **插件与仪表盘：**TypeScript/ESM Host、DSH 原生 Client、包配置、图标和中英文文案；结构化展示实际运行状态、当前操作、事件/订阅、会话与依赖。未接入系统明确显示计划中，统计缺失显示未知。界面没有默认演示任务，不调用模型生成状态播报。
- **受限 Session 适配：**replyer 默认 `opencode-go / deepseek-v4.1-flash / low`，使用专用原生 preset、受限请求与执行 guard；业务/scope 稳定绑定、原生创建/恢复、取消、卸载清理以及零模型探针。历史和压缩归 DSH，不自建会话日志。探针的创建、flush、释放和归档在真实宿主执行两次；尚未验证真实回复、业务会话恢复或压缩。
- **事件基础：**统一服务及具名 SQLite 命令，类型/schema/主体/scope 校验，幂等发布、订阅修订与暂停、有限回放/gap、一次性订阅、投递租约、旧回执隔离、有限重试、查询与统计。事件与匹配投递在同一数据库事务写入。
- **消费边界：**当前接入注册组件消费与 Agent background 持久引用；后者不是自动向原生 Session 追加消息。尚无 Agent 事件工具、自动续接、时间来源或外部渠道订阅。
- **运行状态：**独立数据库 WorkerThread；本地运行状态锁、序列化持久写、暂停/恢复竞态处理、同步失败时保留未知耐久状态并关闭后续写入、重启保留暂停与 Session 绑定；只读快照及 `shiyu_status` 工具。状态服务只有本地 owner 开发范围，没有完整多用户 Mandate 系统或原生 inbox/请求结果对账。
- **embedding：**Harrier 0.6B Q8_0 固定 artifact、1024 维与 query 模板、向量归一化、loopback HTTP 边界及有界烟雾验证；没有连接长期记忆或索引，没有自动启动服务。

仪表盘中的状态来自本体服务与组件记录：会话检查成功、生成草稿、实际送达是不同事实。当前 `reply.generate` 只返回草稿且 `sent=false`，没有渠道发送能力。暂停关闭新模型操作并发出取消，不假称所有在途效果已撤销。

### 真实宿主过程与证据边界

初次启用时仪表盘为 ready/idle，事件 1、pending 0、failed 0；第一次零推理探针后事件 2。暂停后事件 3；禁用再启用生成新的 instanceId，仍保持 paused，历史累计事件 4，只有一条 `runtime.activity` 订阅。上一次探针显示为历史，当前原生 Session 可用性重新标为 unknown。

暂停时再次尝试探针被 `Runtime is paused` 拒绝，事件仍为 4；恢复后事件 5，第二次探针完整回执成功并归档，最终事件 6、pending 0、failed 0。两次探针合计生成模型推理调用为 0。归档日志由 DSH 保留，所有者可显式取消归档；它不是删除或操作系统隔离保证。

上述只有 **1 次禁用/启用循环、2 次探针**，不声称满足 V24 的 20 次生命周期矩阵，也不证明业务 Session 恢复、模型请求、原生压缩或缓存命中。本地 shell 检查的 SQLite 为 3.53.3，真实 DSH 工作线程读值为 3.53.4；二者分别记录，不混用版本证据。

### 本地 embedding 实测范围

本轮使用用户既有评测产物，固定 upstream revision、GGUF SHA256 与本地 llama-server 二进制身份；Node `v24.19.0`、macOS arm64。测试输入仅有 3 条合成文档、2 条查询和 1 条重复文档，设 120 秒取消期限并执行退出清理；未接取消信号的文件哈希步骤不作严格端到端硬超时承诺。3 个请求共 6 向量，记录的请求耗时为 231 ms。这个数是该小样本实测，不是吞吐或生产延迟指标。

实际 paidModelCalls=0、externalNetworkCalls=0；调用的是本机 loopback embedding 服务。拥有的服务进程正常退出（code 0），未安装常驻服务。完整模型、文件与向量摘要由[机器可读证据](<artifacts/embedding-validation.json>)保存；通用 HTTP 客户端不能据响应证明任意 loopback 服务实际加载了该 GGUF。本轮没有重跑用户原有 102 查询基准，也没有证明 10,000 条记忆检索、删除传播或 V25 全量语义指标。

## 与 V 编号的对应

这些结果是既有 V 编号下的**有限子场景**。没有任何完整 V01–V27 项目因此整体改为通过；特别是 V14 替身不能替代 V24 真实宿主。

| 已测子场景 | 关联 V | 未覆盖的完整门槛 |
|---|---|---|
| SQLite 实际设置、独立线程、schema 指纹、正常 close 排空及本地状态同步错误注入 | V01、V14、V15 | 40 模块契约、长锁停止延迟、磁盘满、强杀、迁移和配额；实际宿主 SQLite 版本仅完成限定核对 |
| 主体/type/scope 校验、只读状态无模型/发布副作用、受限 Session 夹具 | V02、V04、V13 | 真实宿主所有工具准入/执行路径、多用户授权、完整 30/80 条边界矩阵 |
| 发布/订阅幂等、重启、并发建订阅、回放/gap、once 与扇出 | V03、V06、V12 | 原方案全部规模/种子及 crash windows；通用领域提交、DSH Goal/记忆跨后端、外部 effects/outbox |
| 订阅暂停/到期、领取竞争、旧 token 拒绝、有限重试 | V10、V11 | 完整 Mandate/预算、Task/Assignment 与设备 fencing；不可把投递租约当作任务执行完成 |
| 模拟 Session 稳定复用、取消/卸载、模型配置与用量未知 | V04、V13、V14 | 真实业务恢复/压缩/模型请求；会话 generation 和渠道发送闭环 |
| 仪表盘合成 UI、读失败 stale、显式命令与监听清理 | V04、V14；V23/V24 的前置子路径 | V23 三条全系统闭环、完整真实宿主主题/生命周期及 Session 跳转 |
| 真实 DSH 安装、2 次受限零推理探针、1 次禁用/启用、暂停保留和拒绝运行 | V04、V14、V21、V24 的有限子场景 | 原 V24 的 20 次生命周期、完整工具准入矩阵、真实业务 Session 恢复/压缩及生成模型 |
| 固定 Harrier artifact、本地真实向量与两条检索排序 | V07、V25 的前置适配证据 | 长期记忆/真实检索后端，完整数据集、标签、重复轮次和语义指标；不声称 V07/V25 通过 |

事件 `accepted` 表示事件和匹配投递持久受理，`acked` 表示消费者确认，不等于任务成功、Session 已续接或外部动作已完成。测试中的“重启”是关闭再打开，不冒称断电恢复。SQLite 低于 WAL 修复基线时采用 DELETE 模式并报告，不用 Node 版本替代 SQLite 核验，也不把这项设置检查当作完整 WAL 能力验收。
