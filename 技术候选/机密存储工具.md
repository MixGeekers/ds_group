## 当前接入取舍

1. OS Keychain 是当前 macOS 在线秘密设施；复用系统添加、查询、轮换、删除能力，不自造密码管理器。
2. 已部署 pass / gopass / sops 的环境可比较直接调用其现有接口，但本项目没有已部署证据，不为减少一个门面引入第二套在线秘密权威。
3. age 只用于指定接收者的离线恢复材料；工具负责文件格式和加密，识雨不自行规定主密钥格式或实现算法。固定发行版本在验证前记录。
4. 模型工具只接受“以该 SecretRef 执行获准操作”，不返回明文、不写 shell argv、不以剪贴板作为后台秘密传递机制。

## 限制与取舍

- 旧调研记载当时没有 GPG；本轮未探测当前安装状态，也没有因收录而安装工具。pass / gopass / sops 的依赖需按实际方案验证；
- pass 的密钥管理依赖用户手工维护 GPG keyring，与"识雨自主使用、人不参与每次解锁"的目标不匹配；
- 旧调研记载 macOS 钥匙串在当时宿主下可用且无 GUI 弹窗；本轮没有复验，不能将其直接视为当前运行环境的保证。是否采用仍待设计比较。

## 待验证事项

- 如验证跨机器恢复，比较 age 指定接收者恢复包与 restic 独立备份；不把私密材料提交普通 Git 历史当作默认方案。
- `security` CLI 在 GUI 应用子进程外（如 cron/launchd）访问钥匙串是否会弹窗，未验证。
