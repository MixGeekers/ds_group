## 它学什么

- Memory Manager 通过 PPO / GRPO 学习 `ADD / UPDATE / DELETE / NOOP`。
- Answer Agent 学习从检索已召回的记忆中筛选、蒸馏，再回答问题。
- 训练更新模型权重，两部分分阶段优化，并使用下游答题效果提供奖励。

这不是简单的提示词四分类，也不是部署后每收到一条消息就自动训练模型。底层检索器与对已召回材料的选择也不是同一个学习对象。

## 与识雨的关系

- **值得借鉴：**将记忆操作显式化；以未来实际任务结果检验一次记忆操作是否有用，而不只相信模型自述“重要”。
- **不可直接推论：**答题奖励高不等于保存决策符合用户许可、隐私、情感经历的重要性或人格变化规则。
- **权限边界：**即使以后使用训练出的策略，也应由内部生成提案、由 core 控制提交；replyer 不因此获得记忆写权。
- **成熟度判断：**论文参考优先，暂不作为可直接集成的工程依赖。
