# DS-Group 发行与部署验证

当前产品基线为 0.2.0，新增 React + 官方 TS7 构建、附件、实际工具执行和提及界面。首个框架与 0.1.0 发行工程历史按下方对应提交和 CI 核对，0.2.0 的结果见[实施记录](实施记录.md)。部署入口见 [deploy/README.md](deploy/README.md)。

## 支持范围

2026-11-04，用户将正式发行和 CI 范围收敛到 Linux amd64/arm64 与 Docker/Compose。

| 环境 | 发行方式 | 自动验证 |
|---|---|---|
| Linux x64 | Docker Engine 与 Compose v2，或 Node 24.x 独立节点 | 模块、源码包干净安装、真实 Synapse/Core 部署、独立 DSH 重启 |
| Linux ARM64 | 同上，镜像自动选择 ARM64 | 同上 |

Linux 部署以 Docker Engine 和 Compose v2 能正常运行为前提，核心镜像固定 Debian Bookworm 用户空间。CI 的宿主为 Ubuntu 24.04，其他 Linux 发行版或 NAS 宿主的适配条件相同，但不把它们列为逐一实机验收。暂不提供 32 位 ARM、RISC-V 或多副本数据库部署。

最低 Node 版本为 24.19.0，支持 24.x。CI 同时运行固定最低版本与最新 24.x。Synapse 固定 1.164.2 的多架构 OCI index，DSH 固定官方 npm 0.2.1-rc.5，DS-Bot 固定 0.2.7。远端模型配置仅保留 `opencode-go/deepseek-v4.1-flash`，发行 CI 不携带真实模型凭据，也不运行生成回合。

## CI 与发行

[检查工作流](https://github.com/MixGeekers/ds_group/blob/main/.github/workflows/ds-group-ci.yml)在应用或相关 workflow 变化时运行，包含 4 个 Linux 架构/Node 组合、2 个 Linux 容器部署组合、2 个独立 DSH 宿主组合、1 个 Chromium 浏览器任务和 1 个汇总门禁，共 10 个任务。矩阵中任一检查失败，汇总失败。

两个 Linux 架构分别使用 Node 24.19.0 和最新 24.x 执行 TS7 类型检查和 React 生产构建，源码解包后再次干净安装与构建。DSH 宿主任务增加本地脚本 provider 驱动的真实工具执行与取消检查，远端模型用量为 0。浏览器任务覆盖提及、聊天草稿、成果、设置与主题/语言交互。

源码包先按白名单收集，再生成逐文件 SHA256 manifest 和归档校验文件。检查会将归档解包到空目录，执行 `npm ci` 和完整模块验证，容器也从已解包的发行内容构建。包内包含部署说明、锁文件和 DS-Bot 许可，不包含 `.local`、凭据、历史运行证据、依赖目录或依赖符号链接。

[发行工作流](https://github.com/MixGeekers/ds_group/blob/main/.github/workflows/ds-group-release.yml)只由 `ds-group-v版本号` 标签触发，并核对标签与 `package.json` 版本。它先复用完整 CI，再分别构建、推送 amd64/arm64 镜像摘要并合并版本 manifest，最后发布 GitHub Release 源码包、校验清单及镜像 index。镜像包含构建来源和 SBOM。普通分支推送只做检查，不发布版本。

```sh
npm ci --ignore-scripts
npm run check
npm run release:pack
npm run release:verify
```

## 0.2.0 Linux 与 Docker 验证

提交 `d3c3fc6` 的 [Linux/Docker CI](https://github.com/MixGeekers/ds_group/actions/runs/41867044916)通过全部矩阵汇总门禁，共 10 个任务。两种 Linux 架构分别完成 10 项真实容器部署、重建及备份恢复检查，独立 DSH 各完成 10 项升级/重启与 5 项真实工具/取消检查，浏览器完成 41 项交互检查。各验证使用合成数据，远端模型调用为 0。源码包包含 215 个文件，本机与 CI 的归档 SHA256 一致。完整摘要与下载证据见[本轮 CI 记录](artifacts/file-work/linux-ci-validation.json)。

## 历史发行证据

2026-11-04，提交 `684c79a` 的[首轮远端 CI](https://github.com/MixGeekers/shiyu/actions/runs/41835621391)共 16/16 个任务成功。10 个原生系统/Node 组合均完成模块检查和发行包干净安装；Linux amd64/arm64 原生 runner 各完成 10 项真实部署检查；Linux x64/ARM64 与 macOS ARM64 各完成 8 项官方 npm DSH 零模型检查。本机模块用例 62/62 通过，Windows 跳过仅适用于 Unix CLI 发现的一项用例。

报告已纳入仓库的 `artifacts/release-ci-validation.json` 及 `artifacts/release-ci/`。源码归档含 153 个文件，本机与 CI Linux 构建的 SHA256 一致。两份 systemd 单元通过 `systemd-analyze verify`，实际开机托管尚待目标服务器验证。本次没有推送版本标签、发布 GitHub Release 或 GHCR 镜像。相同版本只发布一次，已创建 Release 的重复运行会在创建步骤失败，应先核对原发布状态。

容器测试验证空卷初始化、真实密码登录、创建群聊、消息送达、完整容器重建后的账号/房间/消息/VAPID 保持，以及相同请求的去重；另完成停机备份并恢复到全新数据卷。导出的目标 Bot 凭据经实际适配进程连接核心和 Matrix 并完成同步，推理桥接只使用注册夹具。跨历史版本数据库迁移尚无实测，升级前按部署说明备份。

独立 DSH 测试验证插件加载、唯一模型目录、原生 Session 创建、重启后的身份保持、导入核心地址及有序停止。测试使用拒绝所有模型请求的核心替身，另由容器测试验证真实核心与 Matrix。两项结果不替代多台物理机器上的真实模型协作、长期运行或手机通知实机验收。
