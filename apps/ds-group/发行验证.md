# DS-Group 发行与部署验证

本轮基线为 0.1.0。首个框架已提交到 `codex/ds-group-framework`，发行工程在 `codex/ds-group-release-ci` 推进。部署入口见 [deploy/README.md](deploy/README.md)。

## 支持范围

| 环境 | 发行方式 | 自动验证 |
|---|---|---|
| Linux x64 | Docker Engine 与 Compose v2，或 Node 24.x 独立节点 | 模块、源码包干净安装、真实 Synapse/Core 部署、独立 DSH 重启 |
| Linux ARM64 | 同上，镜像自动选择 ARM64 | 同上 |
| macOS Apple Silicon | Docker Desktop 核心，npm 或桌面 DSH 节点 | 模块、源码包干净安装、独立 DSH 重启 |
| macOS Intel | Docker Desktop 核心，npm DSH 节点 | 模块、源码包干净安装；DSH 宿主尚无本轮对应架构实测 |
| Windows x64 | Linux 容器或 WSL2 部署完整服务 | Windows 原生模块和源码包干净安装；原生 Windows DSH 进程管理不在支持范围 |

Linux 部署以 Docker Engine 和 Compose v2 能正常运行为前提，核心镜像固定 Debian Bookworm 用户空间。CI 的宿主为 Ubuntu 24.04，其他 Linux 发行版或 NAS 宿主的适配条件相同，但不把它们列为逐一实机验收。暂不提供 32 位 ARM、RISC-V 或多副本数据库部署。

最低 Node 版本为 24.19.0，支持 24.x。CI 同时运行固定最低版本与最新 24.x。Synapse 固定 1.164.2 的多架构 OCI index，DSH 固定官方 npm 0.2.1-rc.5，DS-Bot 固定 0.2.7。远端模型配置仅保留 `opencode-go/deepseek-v4.1-flash`，发行 CI 不携带真实模型凭据，也不运行生成回合。

## CI 与发行

[检查工作流](https://github.com/MixGeekers/shiyu/blob/codex/ds-group-release-ci/.github/workflows/ds-group-ci.yml)在应用或相关 workflow 变化时运行，包含 10 个原生系统/Node 组合、2 个 Linux 容器部署组合、3 个独立 DSH 宿主组合和一个汇总门禁。矩阵中任一检查失败，汇总失败。

源码包先按白名单收集，再生成逐文件 SHA256 manifest 和归档校验文件。检查会将归档解包到空目录，执行 `npm ci` 和完整模块验证，容器也从已解包的发行内容构建。包内包含部署说明、锁文件和 DS-Bot 许可，不包含 `.local`、凭据、历史运行证据、依赖目录或依赖符号链接。

[发行工作流](https://github.com/MixGeekers/shiyu/blob/codex/ds-group-release-ci/.github/workflows/ds-group-release.yml)只由 `ds-group-v版本号` 标签触发，并核对标签与 `package.json` 版本。它先复用完整 CI，再分别构建、推送 amd64/arm64 镜像摘要并合并版本 manifest，最后发布 GitHub Release 源码包、校验清单及镜像 index。镜像包含构建来源和 SBOM。普通分支推送只做检查，不发布版本。

```sh
npm ci --ignore-scripts
npm run check
npm run release:pack
npm run release:verify
```

## 本轮证据

本地已验证真实 Linux ARM64 容器启动与独立 npm DSH 的零模型 Session 重启。多系统远端 CI 的执行结果由本轮实施记录和 `artifacts/release-ci-validation.json` 登记，未执行的环境不以配置文件代替通过证据。

容器测试验证空卷初始化、真实密码登录、创建群聊、消息送达、完整容器重建后的账号/房间/消息/VAPID 保持，以及相同请求的去重。它覆盖同一版本的容器替换和数据持久化。跨历史版本数据库迁移尚无实测，升级前按部署说明备份。

独立 DSH 测试验证插件加载、唯一模型目录、原生 Session 创建、重启后的身份保持、导入核心地址及有序停止。测试使用拒绝所有模型请求的核心替身，另由容器测试验证真实核心与 Matrix。两项结果不替代多台物理机器上的真实模型协作、长期运行或手机通知实机验收。
