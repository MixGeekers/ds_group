DSH 检查使用隔离宿主和本地拒绝生成的 provider，实际本地、远端模型生成均为 0。先核对纯 `state` 不创建 Bot，再通过真实页面显式创建首个 Bot，验证参与设置、私有配置和原有 Bot 工作区。首轮内核 schema 失败及后续测试脚本的时序、断言范围问题分别保留，未改写为成功。

Core 只读观察覆盖识雨、知秋、听澜的独立身份、真实内核活动、已应用的自然参与模式，以及各自的人物、项目和来源视图。三个判断服务当时报告 `gpt-6-luna` 已配置且可用；这是同一观察窗口的实际 heartbeat。已打开的项目视图只有来源历史、没有当前项目陈述，按实际值记录。来源行数是界面行数，可能包含重复引用。

本 UI 工作发起的模型生成、故事消息和参与模式变更均为 0。页面正常发出的 6 次 presence 与 2 次已读回执单列记录；并行自然剧本的模型调用和行为评分由其独立证据负责。本轮拓扑为同一物理宿主上的真实进程和服务，不代表物理跨机器验收。

生产构建与 12 个浏览器测试文件通过。浏览器回归中的合成 API、真实 controller 加合成 native runtime、实际 DSH 发行包、真实 Core 只读界面，分别注明证据级别；最终新增的账号隔离断言另有 13 项定向检查，不将其回填为先前全量运行。
