## 证据级别

模块测试包含真实本地 HTTP 的 Matrix/Core 协议夹具到 NativeConnections/BotNode/NativeBridge 的投递路径；原生 Agent 在这个夹具中是替身。真实 DSH 烟测另外执行原版工具，用本地脚本 provider 验证创建伙伴、文件、记忆工具和断开后普通本地对话。两者不得合并声称已经跑过完整真实联邦 + 原生模型业务闭环。

浏览器 11 个文件：全量首次 9 个通过，另外两个仍引用旧创建表单；更新既有 Bot 选择与关闭入口后，两文件复验通过。最终模块 400/400。模型选择/连接生命周期末次小改另做定向复验；成员身份更新的末次修补另通过 10 项定向检查。

真实宿主 UI 使用发行包、DSH 0.2.1-rc.5 Web 外壳及本地 provider，验证原生模式切换、DSCord 本机 Bot 列表、模型保存与宿主主题。此截图中的 Core API 是合成夹具，未连接真实 Matrix 房间。

远端模型调用 0；记忆多群语义、原生交互卡片全部转接、断开后结果补发、长时间定时任务与物理跨机仍未在本轮验收。

## 复验命令

```sh
npm test

npm run build
node scripts/native-bot-smoke.mjs
node scripts/native-ui-smoke.mjs
```

原生烟测创建独立合成 DSH profile，不接触用户实际团队。日志可能含一次性宿主认证地址，留在被忽略的本地临时目录；公开证据仅保存工具名、合成结果及截图。
