# 模型选择验证目录

更新于 2026-11-05（America/Caracas）。

| 文件 | 内容与范围 |
|---|---|
| [validation.json](validation.json) | 本轮源码哈希、388 项模块检查、11 组浏览器回归、原生 DSH 选择与 Session 验证、两组本地脚本 provider 及发行包完整性 |
| [真实 DSH 浅色截图](../../assets/model-settings/dsh-model-selection.png) | 在隔离 DSH Web 外壳内安装发行包，通过原生控件登录并保存模型选择 |
| [真实 DSH 深色截图](../../assets/model-settings/dsh-model-selection-dark.png) | 同一 DSH 页面响应宿主主题切换 |

本轮运行环境为 macOS ARM64、Node 24.19.0、DSH 0.2.1-rc.5。原生宿主验证采用隔离 profile，截图连接合成 Core API，截图中的 Bot 已断开。浏览器夹具另覆盖运行中保存选择和明确重连后应用的交互。

最终两组脚本 provider 各执行 6 次本地请求，使用真实 DSH 文件与后台作业工具、真实核心预算类，核对请求模型、回执和账目。远端付费模型调用为 0。Linux 双架构与真实远端服务商本轮未重新运行。

初轮 HTTP 状态断言、浏览器标签匹配、DSH 启动认证和预览说明弹窗阻挡等测试问题分别修正后复验。新增服务器策略测试发现上线前检查过晚且错误码丢失，修复后全量回归通过。失败分类与最终结果一并记录在 JSON 中，私有原始日志保存在被 Git 排除的 `.local/`。

使用与迁移方法见[模型配置与迁移](../../模型配置与迁移.md)。
