## 如何使用

- 沿模块继续补充有实质内容的设计；区域 README 提供下级导航，[目录](<目录.md>)可逐项对应图中的区域与节点。
- 当前接口、复用与验证基线以[完整方案](<完整架构方案.md>)、[复用方案](<复用方案.md>)和[公共契约](<跨模块契约.md>)为准；[总体架构](<../总体架构.md>)提供摘要，[角色边界](<../内外双工与角色边界.md>)和[主动运行专题](<../主动运行、自愈与多设备.md>)保留用户约束及早期比较，不用旧技术判断覆盖v1.1。
- 候选证据继续放在[技术候选](<../../技术候选/目录.md>)与[research](<../../research/README.md>)；新实验遵守[测试目录约定](<../../测试/README.md>)。现有资料工作台位置与内容保持不变。

## 目录边界

- 资料导航层级不等于模型、进程或操作系统权限层级。目录本身不提供隔离。
- 外层对内部状态只读，内外双工仅描述消息流向；worker 已在本轮基线归入任务执行角色，具体本地或远端执行器按能力适配。
- 宿主外恢复不构成独立智能核心，DSH 退出时核心判断与调度暂停。
- “预留空间”及“独立备份”保存设计说明；没有因此分配容量、部署数据库或建立备份故障域。“凭据引用”不接收密钥明文。
- DSH 底座、设备端和外部依赖目录不表示已安装、接入或复制第三方实现。
