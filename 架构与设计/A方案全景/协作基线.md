## 本轮共同边界

- A：一个权威中心，core 在 DSH 插件内；宿主退出时语义判断暂停。设备端为执行器，外部监督器不是第二个 core。
- 内层六部分与外层只读、内外双工保持；worker 为受控执行角色，不能直接提交内层权威状态。角色不是固定模型或进程数量。
- 规划可以作出明确的建议基线及默认值，不将所有问题留为待定；技术未验证处须给失败时备选。用户参数可用合成场景与可配置默认值封闭，不必阻塞方案完成。
- 不安装、部署或运行候选，不创建真实数据根、设备配置或运行组件。只写分工范围内的方案与证据；工作台保持原样。

## 接口协调起点

以下是供各模块细化的统一命名，具体字段由总集成收敛：

| 对象 | 含义与约束 |
|---|---|
| EventEnvelope | 输入与系统事件；稳定 eventId、type、schemaVersion、occurredAt、source、actor、correlationId、payloadRef；会话 / 目标 / 任务关联可选；载荷不是授权 |
| Goal | 持续目标，包含范围、完成条件、预算、暂停 / 到期状态 |
| Mandate | 有版本的行动授权与范围，独立于模型文本与任务状态 |
| Task / Assignment | 工作事项与一次执行实例分离；一个任务可有多次尝试，租约与 fencing 防迟到结果 |
| Proposal / CommitReceipt | 模型或 worker 产生变更提案，程序校验身份、权限、版本后受控提交并给回执 |
| ReadView | 裁剪的只读视图；标记版本、新鲜度、来源和访问范围，不包含写入能力与凭据 |
| Effect / Receipt | 待执行外部动作与实际效果回执；至少一次投递，不宣称任意动作恰好一次；未知结果先核对 |
| DeviceCapability | 稳定设备身份、能力版本、授权范围、可用状态；连通不等于能力有效 |

默认探索方向为 TypeScript 复用 DSH 模型 / Session / 工具 / 事件 / 存储接口，单机 SQLite 事务作为领域状态与任务账本候选，文件作为产物 / 大对象；不默认引入 Redis、Kafka、Kubernetes 或另造 Agent 宿主。是否复用 DSH SQLite provider、如何保证跨表事务与受控写入，由宿主与数据专题核查后统一。
